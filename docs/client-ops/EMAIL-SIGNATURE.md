# Email signature — install guide

Files:

- [`email-signature.html`](email-signature.html) — paste into Gmail / Workspace  
- [`email-signature-plain.txt`](email-signature-plain.txt) — plain-text fallback  

Brand reference: [BRAND.md](BRAND.md).

## Gmail / Google Workspace

1. Open [Gmail](https://mail.google.com) signed in as `ian@webstarbusinessservices.com`.  
2. Settings (gear) → **See all settings** → **General** → **Signature**.  
3. Create signature name: `Webstar`.  
4. Open `email-signature.html` in a browser → Select all → Copy.  
5. Paste into the Gmail signature editor.  
6. If the star image is broken: insert image manually and point to a **public URL** (e.g. `https://www.webstarbusinessservices.com/assets/images/star-icon-teal.png`) or upload the PNG into the signature.  
7. Set signature for new emails (and replies if desired) → **Save Changes**.  
8. Send a test message to yourself and open on phone + desktop.

## Tips

- Keep one signature for Webstar; avoid stacking personal + business signatures.  
- Signature is **not** an invoice; Stripe branding is separate.  
- Update phone/email only via [BRAND.md](BRAND.md) / site config so NAP stays consistent.
