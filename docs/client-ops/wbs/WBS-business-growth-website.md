# Internal WBS — Business Growth Website

**Audience:** Webstar ops only. Do not send to clients.  
**Public version:** “How we work” on `/packages/business-growth-website/`.  
**Annex:** [ANNEX-business-growth-website.md](../agreements/ANNEX-business-growth-website.md) · Hosting: [HOSTING-STANDARD.md](../HOSTING-STANDARD.md)

Phases: Planning → Building → Deployment → Google and growth.  
Nothing is default — fill from the written estimate. Google services are always included.

---

## 3.1 Planning

- 3.1.1 Discovery workshops / requirements
- 3.1.2 Written estimate ($2,500+): features, integrations, page count, marketing extras, growth items
- 3.1.3 Paste estimate bullets into the contract fill-in block
- 3.1.4 Milestone payment schedule (e.g. 40/30/20/10) or 50/50
- 3.1.5 Architecture: hosting path, staging, repos, third-party accounts; Cloudflare DNS; client Google account
- 3.1.6 Content + asset plan; RACI (Webstar vs client)
- 3.1.7 Risk register (integrations, data migration, approvals); weekly status cadence

## 3.2 Building

- 3.2.1 Environment + repo + security baseline
- 3.2.2 Core site / app milestones per estimate
- 3.2.3 Integrations (booking, CRM, payments, calendars — as listed)
- 3.2.4 Custom marketing materials (as estimated)
- 3.2.5 Admin/tools only if estimated
- 3.2.6 QA plan: functional, mobile, integration, accessibility pass
- 3.2.7 Mid-milestone review + payment gate

## 3.3 Deployment

- 3.3.1 Staging acceptance
- 3.3.2 Production cutover runbook (DNS, SSL, env secrets, backups, redirects)
- 3.3.3 Go-live verification against estimate checklist
- 3.3.4 Training / handoff doc for client operators; credentials via password manager
- 3.3.5 Final milestone invoice; warranty clock starts

## 3.4 Google and growth

- 3.4.1 GBP create/claim, complete, verify; GA4 with key events; Search Console + sitemap; ownership to client
- 3.4.2 Measurement baseline (conversions, calls, bookings) recorded at launch
- 3.4.3 SEO / content roadmap for first 90 days (scoped items only)
- 3.4.4 Conversion improvements (CTA, landing tests) if estimated
- 3.4.5 Marketing campaigns / email / ads only if in estimate
- 3.4.6 Growth review cadence (if Care Plan or retainer; else one post-launch growth sprint)
- 3.4.7 Change-order backlog for out-of-estimate requests; request Google review at close
