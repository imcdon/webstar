# Internal WBS — Business Website

**Audience:** Webstar ops only. Do not send to clients.  
**Public version:** “How we work” on `/packages/business-website/`.  
**Annex:** [ANNEX-business-website.md](../agreements/ANNEX-business-website.md) · Hosting: [HOSTING-STANDARD.md](../HOSTING-STANDARD.md)

Phases: Planning → Building → Deployment → Google.

---

## 2.1 Planning

- 2.1.1 Discovery call: goals, competitors, booking tool choice
- 2.1.2 Lock page list (5–10) and booking path (one third-party, written); set exact `{PRICE}` inside $900–$1,800
- 2.1.3 Brand kit brief (2 flyers, card, letterhead, signature)
- 2.1.4 Content inventory: who writes what; photo list
- 2.1.5 Hosting path, domain in client’s name, Cloudflare DNS; client Google account confirmed
- 2.1.6 Agreement + deposit; `{PROJECT_SUMMARY}` with booking tool named; portal login
- 2.1.7 Project schedule (site + brand kit parallel tracks); weekly status cadence

## 2.2 Building

**Site track**

- 2.2.1 Scaffold, design system, shared layout
- 2.2.2 Build approved pages (content + CTAs)
- 2.2.3 Contact form + GA4 events (form submit, tel click, booking click)
- 2.2.4 Booking integration (link, embed, or documented single integration)
- 2.2.5 Portfolio/gallery or services deep pages as scoped
- 2.2.6 SEO: titles, LocalBusiness/schema, sitemap/robots, redirects from old URLs if replacing a site
- 2.2.7 Accessibility pass; mobile + booking-path QA

**Brand kit track (parallel)**

- 2.2.8 Flyer A + Flyer B
- 2.2.9 Business card + letterhead + email signature
- 2.2.10 Collateral QA and revision rounds (2 included across all deliverables)

## 2.3 Deployment

- 2.3.1 Staging site + brand kit draft package for approval
- 2.3.2 Build complete notice → balance invoice (50/50 projects)
- 2.3.3 Production launch per hosting path (DNS/SSL/Cloudflare)
- 2.3.4 Live booking + form verification; 404/redirect check
- 2.3.5 Final brand kit file handoff (print-ready PDFs + signature HTML)
- 2.3.6 Handoff credentials via password manager; archive backup; launch checklist signed off; warranty clock starts

## 2.4 Google

- 2.4.1 GBP create/claim under client account; complete profile; photos; services; booking link on profile
- 2.4.2 Verification started and tracked
- 2.4.3 GA4 property + tag; key events; link GSC
- 2.4.4 Search Console property + sitemap submission
- 2.4.5 Ownership confirmed to client; Webstar manager only
- 2.4.6 Launch announcement assets (reuse flyer or short social pack from brand)
- 2.4.7 First check-in 7–14 days after launch; Care Plan mentioned once
- 2.4.8 Close project; request Google review
