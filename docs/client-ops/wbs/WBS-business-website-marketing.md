# Internal WBS — Business Website and Marketing Package

**Audience:** Webstar ops only. Do not send to clients.  
**Public version:** “How we work” on `/packages/business-website-marketing/`.  
**Annex:** [ANNEX-business-marketing.md](../agreements/ANNEX-business-marketing.md)

Phases: Planning → Building → Deployment → Growth.

---

## 3.1 Planning

- 3.1.1 Discovery call: goals, competitors, booking tool choice
- 3.1.2 Lock page list (5–10) and booking path (one third-party, written)
- 3.1.3 Marketing collateral brief (2 flyers, card, letterhead, signature)
- 3.1.4 Content inventory: who writes what; photo list
- 3.1.5 Agreement + deposit; exact `{PRICE}` and `{PROJECT_SUMMARY}` with booking tool named
- 3.1.6 Project schedule (site + collateral parallel tracks)

## 3.2 Building

**Site track**

- 3.2.1 Scaffold, design system, shared layout
- 3.2.2 Build approved pages (content + CTAs)
- 3.2.3 Contact form
- 3.2.4 Booking integration (link, embed, or documented single integration)
- 3.2.5 Portfolio/gallery or services deep pages as scoped
- 3.2.6 SEO: titles, LocalBusiness/schema if local, sitemap/robots
- 3.2.7 Mobile + booking-path QA

**Marketing track (parallel)**

- 3.2.8 Flyer A + Flyer B
- 3.2.9 Business card + letterhead + email signature
- 3.2.10 Collateral QA and revision rounds

## 3.3 Deployment

- 3.3.1 Staging site + collateral draft package for approval
- 3.3.2 Production site launch (DNS/SSL/hosting)
- 3.3.3 Live booking + form verification
- 3.3.4 Final collateral file handoff
- 3.3.5 Balance due; launch checklist signed off

## 3.4 Growth

- 3.4.1 Google Business Profile basics (claim/verify guidance or setup assist as scoped)
- 3.4.2 Analytics + Search Console property connect (or client instructions)
- 3.4.3 Launch announcement assets (reuse flyer or short social pack from brand)
- 3.4.4 30-day check-in: rankings/clicks notes, one content or CTA tweak recommendation
- 3.4.5 Optional upsell path documented (retainer / ads — not included unless change order)
