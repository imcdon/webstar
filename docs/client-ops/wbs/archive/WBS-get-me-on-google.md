# Internal WBS — Get Me On Google

**Audience:** Webstar ops only. Do not send to clients.  
**Public version:** “How we work” on `/packages/get-me-on-google/`.  
**Annex:** [ANNEX-get-me-on-google.md](../agreements/ANNEX-get-me-on-google.md)

Phases: Planning → Building → Deployment → Growth.

---

## 1.1 Planning

- 1.1.1 Intake: legal/trade name, address, phone, website, hours, service area, categories, photos
- 1.1.2 Confirm existing GBP (claim) vs new create; note Google account email
- 1.1.3 Confirm site URL for GA4 tag (or Analytics-only if no site yet)
- 1.1.4 Agreement + full payment gate ([WORKFLOW.md](../agreements/WORKFLOW.md))
- 1.1.5 Drive folder: Agreement / Invoices / Assets (photos, NAP sheet)
- 1.1.6 Scope summary email

## 1.2 Building

- 1.2.1 Create or claim Google Business Profile
- 1.2.2 Complete NAP, categories, description, hours, services, attributes
- 1.2.3 Upload and caption photos (logo, exterior, work if provided)
- 1.2.4 Create GA4 property; configure data stream
- 1.2.5 Install basic site tag (gtag / GTM lite) when client grants hosting or CMS access
- 1.2.6 Optional: Google Search Console property notify if site exists and DNS/HTML tag available
- 1.2.7 Internal QA: NAP consistency vs website/print; hours; category fit

## 1.3 Deployment

- 1.3.1 Start Google verification; document method (postcard / phone / email / video)
- 1.3.2 Client completes verification steps; Webstar follows up until verified or blocked by Google
- 1.3.3 Transfer/confirm Client as primary owner on GBP and Analytics
- 1.3.4 Handoff sheet: login notes, what was set, how to request reviews (no fake reviews)
- 1.3.5 Close build/deploy checklist

## 1.4 Growth

- 1.4.1 First monitoring check-in (7–14 days after tag live / profile active)
- 1.4.2 Review: profile views, search queries (if available), site users/sessions basics
- 1.4.3 One-page plain-English notes + 2–3 next actions (photos, posts, Q&A, hours accuracy)
- 1.4.4 Document optional retainer / ads upsell (not included)
