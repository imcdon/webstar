# Internal WBS — Marketing Package

**Audience:** Webstar ops only. Do not send to clients.  
**Public version:** “How we work” on `/packages/marketing/`.  
**Annex:** [ANNEX-marketing.md](../agreements/ANNEX-marketing.md)

Phases: Planning → Building → Deployment (no Growth).

---

## 1.1 Planning

- 1.1.1 Intake: brand assets (logo, colors, fonts), company legal/trade name, address, phone, email, social URLs
- 1.1.2 Confirm deliverable list: 2 flyers, business card, letterhead, email signature
- 1.1.3 Capture audience, offer, CTA, and any hard constraints (sizes, QR, promo dates)
- 1.1.4 Agreement + full payment gate ([WORKFLOW.md](../agreements/WORKFLOW.md))
- 1.1.5 File Drive folder: Agreement / Invoices / Assets
- 1.1.6 Creative brief one-pager (tone, must-include copy, do-not-use)

## 1.2 Building

- 1.2.1 Flyer A — concept → layout → export print-ready
- 1.2.2 Flyer B — concept → layout → export print-ready
- 1.2.3 Business card — front/back → print-ready
- 1.2.4 Letterhead — align to [LETTERHEAD.md](../LETTERHEAD.md) / brand → PDF (+ editable source if used)
- 1.2.5 Email signature — HTML and/or image per [EMAIL-SIGNATURE.md](../EMAIL-SIGNATURE.md)
- 1.2.6 Internal QA: bleeds/margins, contact accuracy, contrast, print vs screen
- 1.2.7 Client review round(s) per Master Agreement; apply approved revisions

## 1.3 Deployment

- 1.3.1 Package final files (named, format list)
- 1.3.2 Handoff to client Drive/Assets + short usage notes (print specs, Gmail signature paste)
- 1.3.3 Confirm receipt; close project (no growth/retainer)
