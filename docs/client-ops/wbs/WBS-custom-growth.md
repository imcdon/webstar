**Audience:** Webstar ops only. Do not send to clients.  
**Public version:** “How we work” on `/packages/custom-growth/`.  
**Annex:** [ANNEX-custom-growth.md](../agreements/ANNEX-custom-growth.md)

Phases: Planning → Building → Deployment → Growth.  
Nothing is default — fill from the written estimate.

## 4.1 Planning

- 4.1.1 Discovery workshops / requirements
- 4.1.2 Written estimate: features, integrations, page count, marketing extras
- 4.1.3 Paste estimate bullets into annex “Estimate reference”
- 4.1.4 Milestone payment schedule (deposit / mid / launch)
- 4.1.5 Architecture: hosting, staging, repos, third-party accounts
- 4.1.6 Content + asset plan; RACI (Webstar vs client)
- 4.1.7 Risk register (integrations, data migration, approvals)

## 4.2 Building

- 4.2.1 Environment + repo + security baseline
- 4.2.2 Core site / app milestones per estimate
- 4.2.3 Integrations (booking, CRM, payments, calendars — as listed)
- 4.2.4 Custom marketing materials (beyond standard bundle if estimated)
- 4.2.5 Admin/tools only if estimated
- 4.2.6 QA plan: functional, mobile, integration, accessibility spot-check
- 4.2.7 Mid-milestone review + payment gate

## 4.3 Deployment

- 4.3.1 Staging acceptance
- 4.3.2 Production cutover runbook (DNS, SSL, env secrets, backups)
- 4.3.3 Go-live verification against estimate checklist
- 4.3.4 Training / handoff doc for client operators
- 4.3.5 Final milestone invoice

## 4.4 Growth

- 4.4.1 Measurement baseline (analytics, conversions, GBP if local)
- 4.4.2 SEO / content roadmap for first 90 days (scoped items only)
- 4.4.3 Conversion improvements (CTA, landing tests) if estimated
- 4.4.4 Marketing campaigns / email / ads only if in estimate
- 4.4.5 Monthly or quarterly growth review cadence (if retainer quoted; else one post-launch growth sprint)
- 4.4.6 Change-order backlog for out-of-estimate requests
