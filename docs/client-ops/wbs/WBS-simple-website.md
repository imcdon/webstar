# Internal WBS — Simple Website Package

**Audience:** Webstar ops only. Do not send to clients.  
**Public version:** “How we work” on `/packages/simple-website/`.  
**Annex:** [ANNEX-simple-website.md](../agreements/ANNEX-simple-website.md)

Phases: Planning → Building → Deployment (no Growth).

---

## 2.1 Planning

- 2.1.1 Intake: logo, photos, copy notes, preferred colors, CTA goals (call / book link)
- 2.1.2 Lock 3-page sitemap (e.g. Home / About or Services / Contact)
- 2.1.3 Confirm hosting path (client cPanel vs Webstar staging Path A) and domain ownership
- 2.1.4 Agreement + 50% deposit gate; Stripe invoice
- 2.1.5 Scope summary email ([SCOPE-SUMMARY.md](../SCOPE-SUMMARY.md))
- 2.1.6 Tech notes: stack (PHP static pattern), contact form recipient, book/call button targets

## 2.2 Building

- 2.2.1 Repo/scaffold (or client folder), config, paths, security checklist habits
- 2.2.2 Design system: tokens, type, mobile-first layout shell
- 2.2.3 Page 1 — Home (brand, offer, primary CTAs)
- 2.2.4 Page 2 — Services or About (per sitemap)
- 2.2.5 Page 3 — Contact (form + tel + map/hours as provided)
- 2.2.6 Contact form submit path + spam basics
- 2.2.7 Call / Book Now buttons (links only; no custom booker)
- 2.2.8 SEO basics: titles, meta, favicon, OG image
- 2.2.9 Mobile QA + form test
- 2.2.10 Client review rounds; content freeze before launch

## 2.3 Deployment

- 2.3.1 Staging preview (auth gate if on Webstar host)
- 2.3.2 Production deploy (client hosting or agreed path); SSL/DNS checklist
- 2.3.3 Smoke test live (pages, form, CTAs)
- 2.3.4 Collect balance; handoff credentials ownership note (client owns domain/hosting)
- 2.3.5 Close project (no growth phase)
